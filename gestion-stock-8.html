⚙️ Configuration requise

Ce logiciel utilise Firebase (gratuit) pour stocker les données en ligne et les partager entre les employés d'une même structure. La configuration n'a pas encore été renseignée dans le fichier.

  1. Créez un projet sur console.firebase.google.com
  2. Activez Authentication → méthode Email/Mot de passe
  3. Activez Firestore Database (mode production)
  4. Copiez la configuration du projet (icône Web </>) dans la constante firebaseConfig en haut du fichier
  5. Appliquez les règles de sécurité Firestore fournies séparément
